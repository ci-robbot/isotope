A Linux you install once and do not have to maintain.

Isotope is an immutable desktop. The system is one signed image that updates as a whole, and the previous version is always one reboot away. Four desktops and a server edition, built on Hadron, by Kairos.

One image, nothing to break

The system lives in a read-only image. You do not install packages into it, so there is no package manager to break and no half-finished upgrade. Your files stay in /home, and your apps come from Flathub.

Every package is compiled from source on Hadron, a small Linux built on musl. Kairos boots it, upgrades it and encrypts its disk.

Updates that cannot break your machine

Isotope keeps two systems on the disk, A and B. An update goes to the one you are not running.

  1. A release is out

    A tray icon tells you. You are running system A.

  2. It is written to B

    Click to install. Nothing you are using changes.

  3. Reboot when it suits you

    The computer starts the new system.

  4. Changed your mind?

    The previous system is still in the boot menu.

isotope             # installed version and latest release
isotope upgrade     # install the latest release
isotope rollback    # boot the previous system

Only members of the admin group can install updates. Release images are signed with cosign.

Four desktops, the same Isotope

Every desktop has the same Isotope features on the same keys: Super+Esc opens the Isotope menu, Super+F1 shows the shortcuts. They differ in how they arrange your windows.

  • COSMIC

    Windows where you put them, a dock, a graphical login, a settings app and an app store. The one to start with if you are new to Linux.

  • niri + Noctalia

    New windows open to the right, and you scroll through them. Noctalia adds a bar, a dock, a launcher and a control center.

  • Sway

    Tiling on Wayland, for people who drive the computer from the keyboard.

  • i3

    The classic tiling window manager, on the XLibre X server.

Changed your mind later? isotope switch niri moves an installed machine to another desktop and keeps your files.

What comes with it

Try it before you install

The desktop ISOs start a live desktop from the USB stick. Check that the Wi-Fi, the screen and the sound work. Nothing is written to your disks until you choose "Install Isotope", and the installer then opens as a window.

Encrypt your files

The installer offers to encrypt the disk. You type a passphrase at every start, and you can add a recovery key in case you forget it. Encryption is off unless you choose it.

Apps on the first login

A short checklist installs a browser and other essential apps from Flathub. File dialogs and dark mode work in Flatpak apps.

Backups

Everything that survives a reboot, encrypted, to a USB disk or a remote target: files, users, settings and the list of your apps. After the first backup only the changes are copied.

isotope backup schedule daily
System extensions

Add tools to the system without rebuilding its image. Browse, install and remove extensions in Isotope System or from the command line.

isotope ext list
A firewall, on by default

New incoming connections are blocked, except SSH and what a network needs (DHCP, mDNS, ping). Allow or remove ports in Isotope System, or from a terminal.

isotope firewall allow 8080/tcp
Programs built for glibc Coming soon

Isotope is built on musl. Running glibc programs directly is not released yet. Today, use Flatpak apps, or Distrobox, which is included and gives you a normal Linux in a container.

distrobox create

Isotope Server

The same base with no desktop at all: the installer with disk encryption, A/B updates, system extensions, backups, the firewall, NetworkManager, an SSH server and Docker. Log in on the console or over SSH.

isotope upgrade          # the latest server release
isotope backup           # back up the whole machine
sudo nmtui               # the network, in a text UI
docker run --rm hello-world

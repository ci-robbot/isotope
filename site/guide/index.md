# Isotope user guide

This guide tells you how to install Isotope and how to use it every day. Each page is about one task or one part of the system.

> This guide follows the development version of Isotope. Some features on these pages can be missing from the release on your computer. The release notes tell you what each release contains. To read them, open **Isotope System**, go to **About**, and click **What's new in this release**.

## Get started

- [Install Isotope](install.md): download the ISO, try the live desktop, run the installer, encrypt the disk, and use the Trusted Boot edition.
- [First login and Isotope Welcome](first-login.md): the language, the network, the look and your first apps.
- [Desktops, the Isotope menu and keys](desktops.md): the four desktops and the keys that work on all of them.

## Isotope System, page by page

- [Isotope System](isotope-system.md): open it, and find the page you need.
- [Apps](apps.md): find, install, update and remove apps from Flathub.
- [Updates](updates.md): install a new release of Isotope, automatic updates and firmware updates.
- [Desktop and image](desktop-and-image.md): change to another desktop or image.
- [Extensions](extensions.md): add programs to the system.
- [Backup and restore](backup.md): back up the computer, and bring it back on a new one.
- [Security and the recovery key](security.md): the disk encryption keys.
- [Network](network.md): Wi-Fi, VPN, WireGuard, the firewall and mobile broadband.
- [Bluetooth](bluetooth.md): pair devices and send files.
- [Printers](printers.md): add a printer and print a test page.
- [Users](users.md): add people, change passwords and administrators.
- [Disks](disks.md): USB disks, mount, eject and format.
- [Network shares](network-shares.md): folders of other computers, over SMB or NFS.
- [Compatibility](compatibility.md): run programs made for other Linux systems.

## When something goes wrong

- [Go back to the previous version](rollback.md): restart into the system you had before the last update.
- [Get help](help.md): the shortcut sheet, the commands, and how to report a problem.

## Words in this guide

| Word | What it means |
|---|---|
| Administrator | A user in the `admin` group. Only administrators can install updates, change the system and manage other users. The account that the installer makes is an administrator. |
| Super | The key with the Windows logo. On a Mac keyboard, the Command key. |
| Isotope menu | The menu that opens with [[Super+Escape]]. It is the same on every desktop. |
| Isotope System | The window that manages the computer: updates, apps, network, users and more. |
| Release | A version of Isotope, for example v0.2.0. Each release is one complete system image. |

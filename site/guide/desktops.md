# Desktops, the Isotope menu and keys

Isotope has four desktops. Each desktop has the same Isotope features on the same keys. The desktops are different in how they arrange your windows.

| Desktop | How it works |
|---|---|
| **COSMIC** | Windows go where you put them. It has a panel, a dock, a settings app and an app store. Choose it if you are new to Linux. |
| **niri** | New windows open to the right, and you scroll through them. Noctalia adds a bar, a dock, a launcher and a control center. |
| **Sway** | Windows tile next to each other, on Wayland. You use the keyboard for most things. |
| **i3** | Windows tile next to each other, on the X server. You use the keyboard for most things. |

To change to another desktop, see [Desktop and image](desktop-and-image.md).

## The Isotope menu

Press [[Super+Escape]] to open the Isotope menu. Super is the key with the Windows logo. On COSMIC, you can also click the Isotope mark at the left of the top panel.

Type a part of the name of an entry to find it. Press Enter to open it.

| Entry | What it opens |
|---|---|
| **Apps** | The list of your apps. |
| **Install apps** | The [Apps](apps.md) page of Isotope System. |
| **Wi-Fi** | The Wi-Fi networks. |
| **Bluetooth** | The [Bluetooth](bluetooth.md) page of Isotope System. On niri, the Bluetooth panel of the control center. |
| **Audio** | The sound output and volume. |
| **Capture** | A screenshot of the whole screen, or of an area or a window. |
| **Emoji** | The emoji picker. It copies the emoji that you choose. |
| **Night light** | A warmer screen in the evening. Not on COSMIC. |
| **Clipboard** | The clipboard history. |
| **System** | [Isotope System](isotope-system.md). |
| **Update** | The [Updates](updates.md) page of Isotope System. |
| **Extensions** | The [Extensions](extensions.md) page of Isotope System. |
| **Backup** | The [Backup](backup.md) page of Isotope System. |
| **Recovery key** | The [Security](security.md) page of Isotope System. Only on an encrypted disk. |
| **Welcome** | [Isotope Welcome](first-login.md) again. |
| **Help** | The keyboard shortcut sheet and the link to this guide. |
| **Power** | Lock, log out, suspend, restart and power off. |

On the live desktop, the first entry is **Install Isotope**.

## Keys on every desktop

These keys are the same on the four desktops.

| Keys | What they do |
|---|---|
| [[Super+Escape]] | Open the Isotope menu. |
| [[Super+;]] | Open the emoji picker. |
| [[Super+Ctrl+V]] | Open the clipboard history. |
| [[Super+Alt+L]] | Lock the screen. |
| [[Super+Alt+BackSpace]] | Turn do not disturb on or off. |

On Sway, i3 and COSMIC, the clipboard history keeps your last 200 copies in memory until you log out. It does not keep the passwords that a password manager copies.

## Keys on Sway, i3 and niri

| Keys | What they do |
|---|---|
| [[Super+F1]] | Show all the keyboard shortcuts of the desktop. |
| [[Super+Enter]] | Open a terminal. |
| [[Super+D]] | Open an app. |
| [[Super+Shift+Q]] | Close the window. |
| [[Super+Shift+E]] | Open the power menu. |
| [[Super+Alt+N]] | Turn the night light on or off. |
| [[Super+BackSpace]] | Close the newest notification. |
| [[Super+Shift+BackSpace]] | Close all notifications. |
| [[Super+Ctrl+BackSpace]] | Show the last closed notification. On niri, the notification history. |
| [[Print]] | Take a screenshot. |

On Sway and i3, [[Super+N]] opens the Wi-Fi menu, [[Super+Shift+A]] the audio output and [[Super+Shift+B]] Bluetooth. On niri, [[Super+S]] opens the control center.

The night light makes the screen warmer from 20:00 to 07:00.

## Keys on COSMIC

COSMIC keeps most of its own keys.

| Keys | What they do |
|---|---|
| [[Super]] | Open the launcher. |
| [[Super+T]] | Open a terminal. |
| [[Super+Q]] | Close the window. |
| [[Super+W]] | Show the workspaces. |
| [[Super+A]] | Show the app library. |
| [[Super+Shift+Escape]] | Log out. |
| [[Print]] | Take a screenshot. |

On COSMIC, the Isotope quick settings are at the right of the top panel. They hold Wi-Fi, Bluetooth, the keyboard layout and the dark style. They also hold do not disturb, the brightness, the volume and the power actions. Close a notification with a click.

## Find every key

To see all the keys of your desktop, open the Isotope menu and choose **Help**. On Sway, i3 and niri, you can also press [[Super+F1]].

## The update icon

An Isotope icon in the panel tells you when a new release is ready. Its menu shows the state of the updates and opens Isotope System. The icon is not on the live desktop. See [Updates](updates.md).

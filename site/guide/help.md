# Get help

## The shortcut sheet

The shortcut sheet lists the keys of your desktop and the most important commands. To open it, press [[Super+Escape]] and choose **Help**. On Sway, i3 and niri, you can also press [[Super+F1]].

The sheet also shows the address of this guide.

## Help in the terminal

Each command of Isotope has its own help:

| Command | What it shows |
|---|---|
| `isotope help` | All the commands of Isotope. |
| `isotope backup help` | The backup commands. |
| `isotope ext help` | The extension commands. |
| `isotope firewall help` | The firewall commands. |
| `isotope glibc help` | How Isotope runs programs built for glibc. |
| `isotope users help` | The user commands. |

## Find the version

Open Isotope System and choose **About**. The page shows the version of Isotope, the desktop and the image. In a terminal, `isotope` shows the installed version and the latest release.

## When the computer does not start

- If the new system does not start after an update, the computer starts the previous system by itself. See [Go back to the previous version](rollback.md).
- If the screen stays black, choose an entry with **safe graphics** in the boot menu of the USB stick.
- To see the messages of the start, press D when the screen says **Press D for boot details**. You can also choose the boot menu entry that ends in **(boot details)**.

## Report a problem

Report problems on GitHub:

1. Go to the [issues of Isotope on GitHub](https://github.com/kairos-community/isotope/issues).
2. Search for your problem. Someone can have reported it already.
3. If you do not find it, open a new issue.

Write these in the issue:

- The version of Isotope, the desktop and the image, from the **About** page.
- What you did, what you expected, and what happened.
- The exact text of an error message.
- For an installation that failed, the log that the installer saved.

Do not put passwords, recovery keys or backup passwords in an issue.

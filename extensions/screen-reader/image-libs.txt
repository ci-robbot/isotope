# The libraries the screen-reader extension takes from the Isotope image, by
# soname. The extension carries everything else in
# /usr/lib/isotope-ext/screen-reader (see Dockerfile).
#
#   linked   named in DT_NEEDED by an ELF file of the extension. The build
#            stage fails on any other library that is not the extension's
#            own; the test stage puts the build's copies of these on the
#            Hadron base, which is not a desktop image.
#   typelib  opened by GObject Introspection when Orca calls into GTK, GDK,
#            Pango, ATK, GdkPixbuf, cairo or HarfBuzz: the typelibs name the
#            library, and the image's copy is the one that runs.
#
# test/accessibility/check-screen-reader.sh IMAGE checks that COSMIC's and
# niri's images have every one of them.
linked libglib-2.0.so.0
linked libgobject-2.0.so.0
linked libgio-2.0.so.0
linked libgmodule-2.0.so.0
linked libgthread-2.0.so.0
linked libffi.so.8
linked libz.so.1
linked libdbus-1.so.3
linked libpipewire-0.3.so.0
typelib libgtk-3.so.0
typelib libgdk-3.so.0
typelib libatk-1.0.so.0
typelib libpango-1.0.so.0
typelib libpangocairo-1.0.so.0
typelib libgdk_pixbuf-2.0.so.0
typelib libcairo-gobject.so.2
typelib libharfbuzz.so.0
typelib libharfbuzz-gobject.so.0

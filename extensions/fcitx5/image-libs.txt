# The libraries the fcitx5 extension takes from the image, by soname: every
# other library one of its ELF files needs is its own, in
# /usr/lib/isotope-ext/fcitx5. The Dockerfile's build stage refuses any
# other NEEDED entry, and test/input-method/check-input-methods.sh IMAGE
# checks that every desktop image (sway, i3, niri, COSMIC) has each one.
# They are the ones the four desktops share: the C and C++ runtimes, zlib,
# zstd, libsystemd and GLib, and GTK 3's drawing stack below Cairo.
# Cairo itself, Pango, libxcb and libX11 are the extension's own: the
# Wayland desktops' Cairo has no XCB backend, and i3's is another build.
